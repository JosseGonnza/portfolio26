# Brief — dev.jotagestudio.es

> Estrategia del portfolio personal. Actualizar si cambia posicionamiento o audiencia.

---

## Objetivo

Conseguir prácticas en empresa en **marzo 2027** (segundo año DAW, modalidad a distancia).
Secundario: captar proyectos tech fuera del nicho hostelero.

## Audiencia

Recruiters, CTOs y responsables de prácticas de empresas tech.
Pueden llegar vía LinkedIn, búsqueda orgánica, o link compartido directamente.

## Posicionamiento

**Backend developer con criterio de producto.**

No pedir disculpas por ser junior. No decir "en formación" como primera palabra.
La empresa JotaGe Studio (real, en producción, con clientes) prueba que entrega.
El Proyecto 1 (API cartas) prueba que sabe diseñar una API backend con criterio.

Lo que diferencia a Jose de otro estudiante de DAW:
- Tiene una empresa propia funcionando — no proyectos de clase
- Entiende el negocio que resuelve con el código (cocina → hostelería → producto)
- Su stack en producción y su stack académico son complementarios, no contradictorios

## Secciones de la web

1. **Hero** — pitch en una frase + stack principal + CTA + nota de prácticas mar 2027
2. **Stack** — grid separado: producción real vs. académico/aprendizaje
3. **Proyectos** — cards con enlace a caso de estudio de cada uno
4. **JotaGe Studio** — mencionado como proyecto de empresa / prueba de producción
5. **Formación** — DAW (2025-2027) · IBM SkillsBuild · Cocina
6. **Trayectoria** — línea de tiempo: 10 años HORECA → transición → empresa → dev
7. **CV descargable** — PDF con estética JotaGe Studio
8. **Contacto** — email directo + formulario con aviso GDPR

## Tono

Mismo tono de marca que jotagestudio.es: directo, sin florituras, seguro.
Técnico cuando toca. Sin relleno ni frases genéricas de LinkedIn.

## Decisiones de diseño

- Mismo sistema visual que jotagestudio.es (dark #1A1A1A, naranja #FF5733, Syncopate + Inter)
- Coherencia de marca entre la web de empresa y el portfolio personal
- Sin WhatsAppFloat — ese botón es para clientes de hostelería
- Links cruzados: portfolio → jotagestudio.es y viceversa
